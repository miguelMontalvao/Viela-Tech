# Fotos originais

Coloque aqui as fotos da Rocinha (JPG, PNG ou WebP) e rode `npm run imagens`.
O script gera versões AVIF e WebP em vários tamanhos em `public/img/` e atualiza `src/data/imagens.json`.

As fotos originais não vão para o git (só este arquivo). Use apenas fotos da equipe ou com licença que permita o uso, e registre o crédito em `src/data/creditos.js`.
